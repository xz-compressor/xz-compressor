本工具在浏览器本地完成所有压缩与解压，文件不会上传到任何服务器。压缩引擎为 7-Zip 的 WebAssembly 移植（7z-wasm）。

开源许可与版权署名：

  • 7-Zip / 7z-wasm（7zz.wasm、7zz.es6.js）：GNU LGPL + unRAR 限制，版权 © Igor Pavlov 等（npm 包 7z-wasm）
  • RAR 解压器基于 Alexander Roshal 的 unRAR 源码：仅可用于处理 RAR 归档，禁止用于重建 RAR 压缩算法（本工具不提供 RAR 压缩）
  • 本工具编排界面为原创代码，按“现状”免费提供

本 HTML 单文件内联了 7z-wasm 引擎（LGPL + unRAR restriction），可自由使用与分发；完整许可证文本见随 Windows 版提供的 tools\html\7zwasm_License.txt 与 unRarLicense.txt。
