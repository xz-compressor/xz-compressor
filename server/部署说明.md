# 公告发布服务器端（server.py）

这是给管理员用来**发布公告、查看用户反馈**的小服务，零依赖，Python 3.7+ 直接跑。

## 一、它提供什么
- 管理员后台 `http://服务器IP:8350/admin`：登录后写公告（标题+正文），保存即生效；下方能看到所有用户反馈。
- 公开接口 `GET /xz/announce`：返回当前公告纯文本（第一行标题）。
- 接收反馈 `POST /xz/feedback`：把用户反馈追加到 `data/feedback.log`。
- 防刷：同 IP 拉公告冷却 30 秒、提交反馈冷却 60 秒。

## 二、部署到 <your-server>
1. 把整个 `server/` 目录上传到服务器（任意路径）。
2. **改密码**：打开 `server.py`，把 `ADMIN_PASS = "xz-admin-2026"` 改成你自己的强密码。
3. 前台跑一下验证：
   ```bash
   python3 server.py 8350
   ```
   浏览器开 `http://<your-server>:<port>/admin`，输入密码，写一条公告保存。
4. 常驻运行（systemd 示例）：
   ```ini
   # /etc/systemd/system/xz-announce.service
   [Unit]
   Description=XZ Announce Server
   [Service]
   WorkingDirectory=/opt/xz/server
   ExecStart=/usr/bin/python3 /opt/xz/server/server.py 8350
   Restart=always
   [Install]
   WantedBy=multi-user.target
   ```
   ```bash
   sudo systemctl daemon-reload && sudo systemctl enable --now xz-announce
   ```
5. 防火墙/安全组放行 **8350**（如果用 frp/隧道把 14923 转到本机 8350，则放行隧道端口即可，8350 可只监听 127.0.0.1）。

## 三、和隧道 14923 的关系
你的隧道服务把公网端口 **14923** 转发到这台服务器的 **8350**。客户端原本访问 `http://<your-server>:<port>`（直连）或经隧道访问。现在客户端已移除"检查公告/用户反馈"按钮，这个服务**独立运行**：以后若想恢复公告弹窗，只要把 `Remote` 类加回客户端、指向这个地址即可，接口路径不变。

## 四、数据文件
- `data/announcement.json`：当前公告（标题/正文）。
- `data/feedback.log`：每条反馈一行 JSON（时间、IP、类型、标题、内容、联系方式）。
备份时连这两个文件一起备份即可。
